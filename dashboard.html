需要面板密码

这一页的运维操作需要先解锁。解锁后 30 分钟内刷新页面仍然有效。

改用 LB API Key 解锁

忘记面板密码时走这条：有效的 LB API Key 始终可以换会话（持有它的人本来就能调用每个 admin 端点），解锁后可在「面板密码」里重设。

会话以 HttpOnly cookie 承载，页面脚本不持有任何凭据，XSS 也没有可偷的东西。密码来自 LB_DASHBOARD_PASSWORD 或存储里的覆盖值；两者都没有时面板登录整体不可用，不会退化为无密码放行。连续 5 次失败按来源指数退避，退避期内正确密码也会被拒。这一页在入口层已由 OAuth 保护，但 /admin/* 没有，所以凭据仍然必要。

客户端密钥

核对身份并限制可用渠道；密钥在源头轮换。

源头轮换与重读

网关不生成也不存储客户端密钥明文，不提供明文查看或密钥重置。轮换请按以下顺序操作：

1. 在源头改：K8s Secret 或 config.yaml 的 auth.api_keys。
2. 回到这里点「源头已轮换，重读」—— 网关重读 CONFIG_PATH 的 auth 段，不重启、不影响在途请求。
3. 值写成 ${ENV} 形式的取自进程环境，改文件不会改变它们，那种情况仍需一次滚动重启。

重读会立即作废旧密钥，包括你可能正在用来解锁本页的那一把，所以重读成功后会自动锁定。

GHCP 账户范围

先选择一个模型。

配置候选是时点判断，不代表实时流量或推理成功。全局账户状态在账户页修改。

入口与影响范围

客户端密钥仍限制可用渠道；账户选择是集合，不改变会话亲和。/v1/messages 仍只走 ADB。

路由范围、计价与诊断说明

优先序只重排，不绕过客户端密钥限制。账户候选来自已读取的配置与能力快照，未按具体密钥、API 入口或会话模拟请求。给具体 claude-* 显式配置 GHCP/Foundry 偏好，才会开放其 Responses / Chat 入口；清除整条规则会撤销此放行。databricks-claude-* 用公开 API 参考价，裸 claude-* 用 GHCP 分档参考价。

GHCP 账户

启用状态与允许模型影响所有模型规则；单个模型的账户选择在「路由规则」设置。

为什么启用账户后仍没有候选模型？

模型侧的指定账户、账户允许模型和上游能力快照共同筛选，任一层都可能排除账户。到「路由规则」选择模型，可查看首个排除原因。候选覆盖只按已知模型计算，不代表实时流量。

capability 是向上游的时点发现，不是能力认证。允许模型只能缩小范围，有效集 = capability ∩ 允许模型。停用账户请使用启用开关，不要清空勾选。凭据来源与发现时间可在账户详情中查看。

上游凭据

先向上游校验，再封装存储。校验通过与运行加载是两个独立状态。

录入新凭据
校验通过后入库；需滚动重启才加载到运行端点。

通过 GitHub 授权录入

填写账户名 → 开始授权 → 在 GitHub 完成 → 返回检查一次。无需手工粘贴 token。

凭据保护与生效方式

凭据以 AES-256-GCM 封装后存入用量库，密钥来自 LB_CREDENTIAL_KEY（不入库）；未配密钥时录入不可用，不会退化为存明文。页面只显示指纹与校验结果，不显示也不返回明文。运行进程内存仍有明文，封装密钥丢失则凭据不可恢复。录入与删除的运行效果都需下一次滚动重启。

面板密码

更改登录密码。忘记后可用有效的 LB API Key 解锁并重设。

至少 12 个字符。更改成功后其他会话立即失效，当前会话保留。

密码保护、登录退避与多副本边界

存的是 PBKDF2-SHA256 单向验证器，不是密码，不依赖上游凭据的 AES 封装密钥。忘记即不可恢复，可用有效的 LB API Key 解锁后重设。长度按字符计算；错误当前密码会触发登录退避，退避期间正确密码也会被拒绝。

页内修改只对当前副本立即生效；其他副本在重新加载前可能仍接受旧密码。请同步 Secret 并安排滚动重启。

危险操作：清除存储的密码

删除存储覆盖值后回到 LB_DASHBOARD_PASSWORD。环境变量也没配时，密码登录整体不可用，只能用 LB API Key 解锁。
