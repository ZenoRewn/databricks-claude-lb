# 每周价格更新与 Dashboard Logo 实施计划

Author: Zeno Ren

## 交付范围

1. 核对固定 GitHub 官方来源，保存价格表/脚注摘录；补齐 6 个缺价模型。
2. 先建立行为回归，覆盖解析、档位、促销、原子缓存、重启调度、错误保留、取消清理和费用不回算；再实现每 7 天的后台更新。
3. 接入已有服务生命周期与 Copilot Dashboard，提供来源、日期、覆盖数和刷新状态；保留 provider 与实际账单边界。
4. 用 Azure OpenAI `gpt-image-2.5-sunburst` 生成 6 款项目相关 Logo，检查 34px 明暗主题辨识度，供用户选择；用户随后选择 01 汇流，处理透明底并接入。
5. 执行完整本地回归、前端检查、真实公开价格页抓取、应用镜像定向验证和桌面渲染检查；记录实际通过、跳过与未验证范围。

## 技术选择

- 更新在应用进程内运行，成功后 7 天刷新，失败后 1 小时重试，停机后启动时补做过期检查。
- 单一完整价格快照切换，缓存先落盘；官方结构或计费条件无法确认时保留旧表并报告错误。
- 不重算历史金额，不改账本和推理重试逻辑。Logo 采用内嵌 PNG，沿用现有单文件 Dashboard 打包方式。
- 本轮是代码及本地验证，不包含 GitHub 推送、生产部署、生产持久卷配置或实际 Copilot 账单核对。
