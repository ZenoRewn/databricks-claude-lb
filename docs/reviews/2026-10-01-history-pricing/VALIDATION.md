# 历史用量参考费用修复

Author: Zeno Ren

日期：2026-10-01。

## 原因与实现

上一轮每周价格刷新接入 Copilot 实时页，历史页仍调用旧的通用静态表。线上只读检查发现 GPT-6 Astra/Luna/Sol、Gemini 3.8 Flash、Grok 4.6 的历史记录仍未计价；此外，UI 将有价格范围但没有单一金额的记录视为未知。

历史页现按同一份当前公开价格表产生只读参考视图。日输入不足以判断每次请求档位时，给出保守价格上下界，不能将整天输入当作一次长请求。OpenAI 风格输入先扣缓存，Anthropic/Databricks 保留独立缓存分项，避免重复收费。旧参考表只接受明确模型 ID，未知新变体不继承家族价格。

模型汇总、每日表、合计、日均和费用曲线均支持范围；确实无价或过期仍明确显示未知/部分。不会回填供应商账单、改动原始 tokens 或追加账本；实时逐次费用估算保持原逻辑。完整口径见 [价格说明](../../COPILOT_PRICING.md)。

## 验证

- 先建立失败后端与前端回归，复现缺价、日累计误用长档位、缓存重复计费、范围误判未知和不允许修改原始日数据。
- 完整本地回归：777 passed、6 skipped、727 subtests passed，45.22 秒（Python 3.14）；6 个隔离 MySQL 用例未在本地启用。
- 两组 Dashboard Node 检查通过，包含范围累加、部分范围、日均上下界、真实未知和已有 Copilot 实时估算兼容性。
- 对线上近 30 天快照的 199 条模型日记录作只读本地回放，未计价型号由 5 个降至 0 个，原始数据完全不变。此项是本地候选验证，不能替代部署后验收。
- Playwright 桌面合成数据检查：6 个模型、费用区间、上下界曲线、合计与日均均可读；无页面或金额组件横向溢出。[浅色](../../../output/playwright/history-pricing/light.png) / [深色](../../../output/playwright/history-pricing/dark.png)。
